# SketchCut

Оптимизация на разкрой за ПДЧ плочи — подобно на CutMaster2D / SketchCut-lite.

## Функции

- **Плочи** — добавяне на множество плоскости с произволни размери (мм)
- **Детайли** — ширина, дължина, брой; Tab/Enter навигация; въртене per детайл
- **Разкрой** — guillotine алгоритъм с 3 мм kerf (дебелина на диска)
- **Варианти** — всеки клик на „Генерирай" дава нов вариант с различна подредба
- **Кантиране** — 2 мм и 0.5 мм кант с визуален преглед и изчисление в метри
- **Firebase** — проста регистрация/вход, запазване на проекти per потребител
- **PWA** — инсталируемо приложение на телефон

## Стартиране

```bash
npm install
npm run dev
```

## Firebase настройка

1. В [Firebase Console](https://console.firebase.google.com) активирай **Authentication → Email/Password**
2. Създай **Firestore Database**
3. Качи правилата от `firestore.rules`
4. Конфигурацията вече е в `src/lib/firebase.ts`

## PWA икони

```bash
npm run icons
```

## Без акаунт

Приложението работи напълно без вход — разкроите не се запазват.
